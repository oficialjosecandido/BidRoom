How these metrics are counted

Active accounts: Users with isActive: true whose account was created on or before the end of each column's interval (reflects today's activation flag, not a perfect historical replay).

Paid metrics include only transactions with paymentStatus: paid and paidAt falling in the interval. BidRoom fees are the sum of recorded platform fees on those paid transactions (actual rates depend on each listing's terms at sale time).
